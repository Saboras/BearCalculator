# Guide schreiben & veröffentlichen — Anleitung für Autoren

Für Leader mit Schreibrecht (`guides-editor`; Veröffentlichen zusätzlich `guides-senior`
oder Admin). Kein Schreibrecht? → Owner fragt, siehe `POLICY-CHEATSHEET.md`.

## 1. Entwurf anlegen (im Studio)

1. **https://admin.kingdom1516.vip** öffnen und einloggen
2. Links **Content** (Datenbank-Symbol) → **Guide Drafts** → oben rechts **„+"**
3. Felder ausfüllen:

| Feld | Was rein muss | Wichtig |
|---|---|---|
| **Title** | Überschrift des Guides, z. B. „Bear Trap basics" | frei änderbar, jederzeit |
| **Slug** | die Web-Adresse: `kingdom1516.vip/guide/`**`dein-slug`** | ⚠️ **klein-mit-bindestrichen** (z. B. `bear-trap-basics`) und **nach dem Speichern FIX** — gut überlegen, geteilte Links hängen daran |
| **Body** | der Inhalt im visuellen Editor | siehe unten |
| **Category** | eine der drei: Events / Troops & Heroes / Alliance & Transfer | Pflicht fürs saubere Einsortieren |
| **Creator credit** | dein Spielername — wird öffentlich als Autor angezeigt | z. B. „Osmo" |

4. Speichern (Häkchen oben rechts). **Entwürfe sind nie öffentlich** — schreib in Ruhe,
   speicher oft, niemand außer den Leadern sieht sie.

## 2. Was der Editor kann (und was rausfliegt)

- **Überschriften** (fang bei „Heading 2" an — die H1 ist der Titel), **fett/kursiv, Listen, Tabellen**
- **Bilder:** einfach hochladen — die Website verkleinert und optimiert sie beim
  Veröffentlichen automatisch (max. ~1200px, modernes Format)
- **YouTube-Videos** einbetten: erlaubt und funktioniert öffentlich
- **Automatisch entfernt** wird beim Veröffentlichen alles Gefährliche (Skripte,
  Fremd-Einbettungen außer YouTube, Styling-Hacks) — schreib einfach normal, dann merkst
  du davon nichts
- **Sprache: Englisch** — Besucher mit anderen Sprachen übersetzen die Seite per
  Browser-Funktion, deshalb bitte schlichte, klare Sätze

## 3. Veröffentlichen (Senior/Owner)

1. **kingdom1516.vip/admin** → Tab **Guides**
2. Dein Entwurf steht in der Liste mit Status-Chip:
   - **Draft** = noch nie veröffentlicht → Knopf **Publish**
   - **Published** = live und aktuell
   - **Draft newer** = seit der Veröffentlichung weiterbearbeitet → Knopf **Re-publish**
3. Klick auf Publish/Re-publish → nach **~1 Minute** ist der Guide öffentlich unter
   `kingdom1516.vip/guide/<slug>`, findbar über die Kategorien und die Suche

## 4. Ändern & Pflegen

- **Inhalt ändern:** Entwurf im Studio bearbeiten → im Admin **Re-publish** klicken.
  Die Web-Adresse bleibt gleich, geteilte Links funktionieren weiter.
- **Titel ändern:** geht jederzeit (nur der Slug ist fix).
- **Guide offline nehmen:** Owner/Osmo löscht die veröffentlichte Version im Studio
  (Sammlung „Guides") — der Entwurf bleibt als Arbeitskopie erhalten.

## 5. Wenn etwas hakt

| Problem | Lösung |
|---|---|
| Guide erscheint nicht nach Publish | 1–2 Minuten warten, Seite neu laden (die Website baut sich automatisch neu) |
| „Slug already exists" beim Anlegen | Adresse ist vergeben — anderen Slug wählen |
| Publish-Knopf fehlt | Dir fehlt `guides-senior` — Entwurf fertigstellen und Senior/Owner Bescheid geben |
| Bild sieht im Entwurf riesig aus | Egal — die Veröffentlichung verkleinert automatisch |
